# PhotoGuide v0.9.2 — Camera-first

- App launches directly into the camera.
- Removed standalone Home, Onboarding, Settings, Recipe detail, and Camera control pages from the shipping UI.
- Left menu now exposes only Recipe Square, My Recipes, and Create Recipe.
- Selecting a Recipe returns directly to the camera; there is no intermediate detail/start screen.
- Added two guidance layouts: overlay guidance over the full camera preview, and a 7:3 split layout with a dedicated bottom guidance region.
- Question cards remain author-ordered and horizontally swipeable; skip/restore state is preserved across layout switches.
- Camera controls are condensed into the camera surface instead of a separate page.
